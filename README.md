# CS Homework and Learning Archive

本仓库用于整理和记录日常课程学习中的作业、实验、练习、课程项目与学习代码。

## 目录说明

- `CS61a/`：CS61A 课程作业、实验、讨论题与课程项目
- `python_class/`：Python 课程学习内容与课程项目
- `python_lab_class/`：Python 实验课程内容
- `summer2026/`：2026 年暑期课程练习

## 说明

仓库内容主要用于个人学习、复习和进度记录，部分代码可能仍在持续完善中。课程要求与原始材料请以对应课程的官方说明为准。

请遵守相关课程的学术诚信要求，不要直接复制或提交本仓库中的作业答案。
